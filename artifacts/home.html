Guidance is not tool access.

Skills describe how to approach a task. MCP connects an agent to external services. AnyMD keeps those roles separate.

Skills

Local task guidance. Check whether it is installed, then use it when relevant.

MCP connections

Access to external tools and services. Verify availability and permissions in the coding environment.
